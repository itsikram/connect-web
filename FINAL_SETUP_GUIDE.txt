🤖 AI AGENT SETUP - COMPLETE GUIDE

═══════════════════════════════════════════════════════════════

STEP 1: GET YOUR GEMINI API KEY
═══════════════════════════════════════════════════════════════

1. Open your browser and go to:
   https://makersuite.google.com/app/apikey

2. Sign in with your Google account (or create one)

3. You'll see a blue button that says "Create API Key"
   Click it

4. A dialog will appear with your new API key
   Copy it (Ctrl+C)

5. Keep this key safe - you'll need it next


STEP 2: CREATE .ENV FILE
═══════════════════════════════════════════════════════════════

1. Navigate to: E:\Connect\web

2. Create a new file named: .env
   (no extension, just ".env")

3. Open the .env file in a text editor (Notepad, VS Code, etc)

4. Add this line:
   REACT_APP_GEMINI_API_KEY=your_api_key_here

5. Replace "your_api_key_here" with the key you copied
   Example:
   REACT_APP_GEMINI_API_KEY=AIzaSyD-rNo5ch17-5DlriQeix1b_EsVeSrqVJ0

6. Save the file

7. IMPORTANT: Do NOT commit this file to Git!
   Add .env to your .gitignore file


STEP 3: RESTART YOUR APP
═══════════════════════════════════════════════════════════════

1. Stop the dev server:
   Press Ctrl+C in your terminal

2. Clear npm cache (optional but recommended):
   npm cache clean --force

3. Start the app again:
   npm start

4. Wait for the app to compile (takes 10-20 seconds)


STEP 4: CLEAR YOUR BROWSER
═══════════════════════════════════════════════════════════════

1. Open browser developer tools:
   Press F12

2. Clear site data:
   Press Ctrl+Shift+Delete
   
3. Select "All time" and click "Clear"

4. Close and reopen the browser tab

5. Hard reload the page:
   Press Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)


STEP 5: TEST THE AI AGENT
═══════════════════════════════════════════════════════════════

1. Look at the header (top of page)
   You'll see your logo

2. LONG-PRESS the logo
   Hold your mouse button down for 0.5 seconds
   (Not a quick click, but a HOLD)

3. A modal should appear with:
   - "AI Agent Assistant" title
   - A chat interface
   - A green checkmark showing "API Key found"

4. Type a test message:
   "Hello, what can you help with?"

5. Press Enter or click the Send button

6. Wait 1-2 seconds for AI to respond

7. You should see a response from the AI!


VERIFY IT'S WORKING
═══════════════════════════════════════════════════════════════

Look at the browser console (F12 → Console tab):

You should see messages like:
🤖 Sending to Gemini API: { messageLength: 35, historyLength: 0 }
📡 Gemini API Response Status: 200
✅ Gemini API Response received: { candidatesCount: 1, hasText: true }
💬 Final Response: { responseLength: 150, hasSuggestion: false }

If you see these, it's working! ✅


TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEM: Modal won't open
SOLUTION: Hold the logo longer (0.5 seconds). It's a LONG-PRESS, not a click.

PROBLEM: Green checkmark shows "API Key not found"
SOLUTION: 
- Check your .env file exists in /web directory
- Verify REACT_APP_GEMINI_API_KEY line is correct
- Make sure you didn't add spaces: "REACT_APP_GEMINI_API_KEY=KEY"
- Restart the dev server (npm start)
- Hard reload the browser (Ctrl+F5)

PROBLEM: "Invalid JSON payload" error in console
SOLUTION: This means your API key is wrong or missing
- Get a new key from https://makersuite.google.com/app/apikey
- Update your .env file
- Restart dev server
- Hard reload browser

PROBLEM: Response takes forever or times out
SOLUTION:
- Check your internet connection
- Check API key is valid at https://makersuite.google.com/app/apikey
- Check browser console for specific error messages
- Try a different message

PROBLEM: "message.trim is not a function" error
SOLUTION: This has been fixed. Just:
- Clear cache (Ctrl+Shift+Delete)
- Hard reload (Ctrl+F5)
- Restart dev server
