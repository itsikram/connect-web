✅ GEMINI API ERROR FIXED

ERROR THAT WAS FIXED:
=====================
"Invalid JSON payload received. Unknown name "system": Cannot find field"

WHAT WAS WRONG:
===============
The Gemini API doesn't accept a top-level "system" field in the request body.
The correct way is to include system instructions in the contents array.

WHAT WAS CHANGED:
=================
File: src/services/geminiService.js

OLD FORMAT (Wrong):
{
  system: "You are...",
  contents: [...]
}

NEW FORMAT (Correct):
{
  contents: [
    {
      role: 'user',
      parts: [{ text: 'You are an AI assistant...' }]
    },
    ... other messages
  ]
}

TROUBLESHOOTING:
================

If you still see errors:

1. Check console (F12 → Console tab)
2. Look for "❌ Gemini API Error" messages
3. Common issues:
   - API key wrong → get new one at https://makersuite.google.com/app/apikey
   - API key not in .env → add it
   - .env file missing → create it in /web directory
   - Cache issue → clear cache and hard reload

4. Restart dev server:
   - Stop: Ctrl+C
   - Run: npm start


VERIFY .ENV FILE:
=================

Make sure you have a .env file in /web directory with:

Replace "your_actual_key_here" with your real API key from:
